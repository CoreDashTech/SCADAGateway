CoreDash Nexus · เครื่องมือเช็ก/ดึงข้อมูล PW3198 ผ่านสาย LAN (สำหรับคนหน้างาน)
==========================================================================

1) แตกไฟล์ zip ไว้ที่ Desktop
2) ดับเบิลคลิก  CoreDash-PW3198.bat
3) พิมพ์ IP เครื่องวัด แล้วกด Enter  (หลายเครื่องคั่นด้วยจุลภาค เช่น 192.168.10.62,192.168.10.63)

ระบบจะเช็ก 4 ข้อให้เอง:
   [ OK ] คอมอยู่วงเดียวกับเครื่องวัด
   [ OK ] Ping ตอบ            = สายและ IP ถูก
   [ OK ] HTTP                = เปิดหน้าจอเครื่องวัดในเบราว์เซอร์ได้
   [ OK ] FTP                 = ดึงไฟล์ใน SD ได้

แล้วเลือก:
   1 = เปิดหน้าจอเครื่องวัดในเบราว์เซอร์ (ดู/สั่ง Start-Stop จากคอมหรือมือถือ)
   2 = ดึงไฟล์ใน SD ผ่าน FTP (เฉพาะรุ่นที่มี FTP — PW3198 ใช้ PQ ONE ดึงผ่าน LAN แทน)
   3 = ตรวจซ้ำ
   5 = สำรวจช่องทางค่าสด → ได้ไฟล์ PW3198-probe-<IP>-<เวลา>.zip ส่งให้ทีม CoreDash
   4 = ส่งไฟล์ CSV ในโฟลเดอร์ที่ดึงมา เข้าเว็บแอป CoreDash (เปิดหน้า คุณภาพไฟ → ไฟล์ แล้ว plot ให้อัตโนมัติ)
   0 = ออก

ผลตรวจแต่ละครั้งบันทึกเป็น Desktop\PW3198-check-<วันเวลา>.csv

ถ้าขึ้น [FAIL]
   - คอมไม่ได้อยู่วงเดียวกัน → ต่อ Wi-Fi/LAN เดียวกับเครื่องวัด (IP คอมต้องขึ้นต้นเหมือนกัน เช่น 192.168.10.x)
   - Ping ไม่ตอบ → เช็กไฟช่อง LAN, รีบูตเครื่องวัดหลังแก้ IP, IP ห้ามซ้ำกับเครื่องอื่น
   - FTP ไม่ตอบ → ตรวจการตั้งค่า LAN/FTP ในเครื่องวัด (SYSTEM > HARDWARE) และปิด PQ ONE ถ้าเปิดค้างอยู่
   - ถามชื่อผู้ใช้/รหัส → ใส่ค่าที่ตั้งไว้ในเครื่องวัด

คำสั่งแบบไม่ใช้เมนู (สำหรับช่าง IT):
   CoreDash-PW3198.bat -Ip 192.168.10.62 -CheckOnly
   CoreDash-PW3198.bat -Ip 192.168.10.62,192.168.10.63 -Dump
   CoreDash-PW3198.bat -Ip 192.168.10.62 -Dump -Send        (ดึงไฟล์แล้วส่งเข้าเว็บแอปต่อทันที)
   CoreDash-PW3198.bat -Send -Folder "C:\Users\me\Desktop\PW3198-192.168.10.62-20261113-1430"

หมายเหตุ: ไฟล์บันทึกดิบของ Hioki ให้เปิดด้วยโปรแกรม PQ ONE แล้ว Export เป็น CSV
จากนั้นเปิดแอป CoreDash → คุณภาพไฟ → ไฟล์/นำเข้า → นำเข้าไฟล์ เพื่อ plot และวิเคราะห์

    ลำดับ IP = การ์ด: ตัวที่ 1 = #2 MAIN GRID, ตัวที่ 2 = #3 LOAD, ตัวที่ 3 = #6 APF

=== แจ้งเตือนคุณภาพไฟ (ทำงานอัตโนมัติตอนเปิดค่าสด เมนู 8 / LIVE / LIVE-MULTI) ===
    วิเคราะห์ทุก 1 วินาที 12 เงื่อนไข: ไฟดับ, ไฟตก, ไฟเกิน, ไฟกระชาก/สไปก์, ฮาร์มอนิกแรงดัน (THD-U),
    ฮาร์มอนิกกระแส (THD-I), สัญญาณรบกวนความถี่สูง 2–80 kHz, แรงดันไม่สมดุล, ความถี่, PF ต่ำ,
    กระแสนิวทรัลสูง, K-factor สูง + ขาดการเชื่อมต่อเครื่องวัด  (เกณฑ์อยู่ใน pq-alarm-rules.json)
    - ระดับ 🟡 เฝ้าระวัง / 🔴 แจ้งเตือน  · เห็นบนหน้าเว็บแอป "คุณภาพไฟ" ทันที
    - บันทึกทุกเหตุการณ์ลง Desktop\PW3198-alarms-<วันที่>.csv
    - ส่งเข้ามือถือ (ระดับ 🔴 + ตอนกลับสู่ปกติ) ผ่านแอปฟรี ntfy:
        1) มือถือ: ติดตั้งแอป "ntfy" → กด + → Subscribe to topic → ใส่ชื่อหัวข้อในไฟล์ ntfy-topic.txt
           (ไฟล์นี้สร้างอัตโนมัติครั้งแรกที่รัน ชื่อสุ่มยาว — เป็นความลับ อย่าเผยแพร่)
        2) ดับเบิลคลิก CoreDash-PW3198-TEST-PUSH.bat → มือถือต้องเด้งข้อความทดสอบ
        3) โน้ตบุ๊กต้องต่ออินเทอร์เน็ต (เช่น Wi-Fi/มือถือแชร์เน็ต) พร้อมกับต่อ LAN เครื่องวัด
      ต้องการระดับ 🟡 ด้วย: เพิ่ม -PushWarn ต่อท้ายบรรทัด powershell ในไฟล์ .bat

=== ควบคุมจากเว็บแอป (ไม่ต้องกด .bat ซ้ำ) ===
    1) ดับเบิลคลิก CoreDash-PW3198-AUTOSTART-ON.bat ครั้งเดียว → เครื่องมือเปิดเองทุกครั้งที่เปิดโน้ตบุ๊ก (ย่ออยู่ที่ทาสก์บาร์)
    2) เว็บแอป → คุณภาพไฟ → 📡 ข้อมูลจริง:
         🔄 เชื่อมต่อใหม่ทุกเครื่อง / 🔄 ลองเชื่อมต่อใหม่ (รายเครื่อง) / ⚙ ตั้ง IP เครื่องวัด (#2 #3 #6)
    ยกเลิกการเปิดอัตโนมัติ: CoreDash-PW3198-AUTOSTART-OFF.bat
    หมายเหตุ: เว็บแอปเปิดโปรแกรมบนโน้ตบุ๊กเองไม่ได้ (ข้อจำกัดความปลอดภัยของเบราว์เซอร์) จึงต้องให้เครื่องมือเปิดค้างไว้เบื้องหลัง
