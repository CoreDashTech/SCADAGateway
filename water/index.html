ข้อความล่าสุด

ค่าที่อ่านได้ต่อรอบรายงาน (15 นาที)

0 · รับสดจาก MQTT (WebSocket)

เบราว์เซอร์ต่อ broker ผ่าน WebSocket แล้วรับข้อความ drago/dcc/+/shadow/update ทุกมิเตอร์ เลขมิเตอร์มาจาก V4MID ในข้อความเอง · ข้อมูลที่รับได้เก็บไว้ในเครื่องนี้ · รหัสผ่านไม่ถูกส่งไปที่อื่นนอกจาก broker
ยังไม่เชื่อมต่อ

1 · เชื่อม CoreDash Gateway (ใช้งานจริง)

Gateway รับข้อความจาก Drago MQTT ทุก 15 นาที เก็บประวัติ แล้วให้หน้านี้ดึงผ่าน /api/v1 รหัสผ่าน MQTT อยู่ที่ Gateway เท่านั้น

2 · วาง JSON / นำเข้าไฟล์

คัดลอกข้อความจาก MQTTX มาวางได้เลย (หลายข้อความก็ได้) หรือไฟล์ Export จาก MQTTX / .jsonl · ข้อความรูปแบบ Drago จะถูกเก็บรวมกับข้อมูลสดในเครื่องนี้

การจับคู่ฟิลด์

เว้นว่างให้ระบบเดาเอง ใส่ชื่อฟิลด์ (รองรับ a.b) ถ้าเดาไม่ตรง

3 · ตั้งค่าการแสดงผล
