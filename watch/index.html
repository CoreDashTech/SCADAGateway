⚠ PZEM-004T ต่อกับไฟบ้าน 220V โดยตรง อันตรายถึงชีวิต ปิดเบรกเกอร์ก่อนต่อทุกครั้ง และให้ช่างไฟที่มีความรู้เป็นผู้ต่อฝั่งไฟฟ้า
ESP32 DevKit1 ตัวบอร์ดหลัก ต่อ Wi-Fi และส่งข้อมูล

สายจัมเปอร์ เมีย–เมีย4 เส้น5V→5V · GND→GND · PZEM TX→GPIO16 · PZEM RX→GPIO17

ลงโปรแกรมใน ESP32

เปิดไฟล์ด้วย Arduino IDE ติดตั้งไลบรารี WiFiManager และ PZEM004Tv30 เลือกบอร์ด ESP32 Dev Module แล้วกด Upload

ต่อสายและติดตั้ง

ตอบตรง ๆ ก่อนตัดสินใจ

ต้องมีฮาร์ดแวร์ไหม?

ต้องมีครับ โปรแกรมฟรี แต่ต้องมีเซนเซอร์วัดไฟติดที่ปั๊มหรือเครื่องใช้จริง ระบบถึงจะรู้ว่าไฟดับหรือปั๊มหยุด

ไฟดับทั้งบ้าน แจ้งเตือนได้อย่างไร?

ถ้า ESP32 และเราเตอร์มีไฟสำรอง ระบบจะแจ้ง “ไฟฟ้าดับ” ภายในราว 1 นาที ถ้าไม่มีไฟสำรอง อุปกรณ์จะเงียบไป และระบบจะแจ้ง “ขาดการติดต่อ” เมื่อเงียบเกิน 3 นาที

Telegram กับ LINE ต่างกันอย่างไร?

Telegram ส่งได้ฟรีไม่จำกัด แนะนำให้ใช้เป็นหลัก ส่วน LINE ส่งผ่านบัญชีทางการ ซึ่งมีโควตาข้อความฟรีต่อเดือนจำกัด

หมดช่วงทดลองแล้วเกิดอะไรขึ้น?

อุปกรณ์ยังส่งข้อมูลและเห็นค่าล่าสุดได้ แต่ระบบหยุดเก็บประวัติและหยุดแจ้งเตือนจนกว่าจะต่ออายุ ไม่มีการตัดเงินอัตโนมัติ

ข้อมูลของฉันปลอดภัยไหม?

อุปกรณ์แต่ละตัวมีรหัสเฉพาะ ระบบเก็บแบบเข้ารหัสทางเดียว เจ้าของบัญชีเห็นเฉพาะอุปกรณ์ของตัวเอง ทำรหัสหายออกรหัสใหม่ได้ทันที
