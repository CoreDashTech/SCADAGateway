# CoreDash Showcase (/demo/)

หน้าตัวอย่างชุดใหม่ แยกไว้ในโฟลเดอร์นี้ จึงไม่กระทบเว็บหลัก www.coredashtech.com

| ที่อยู่ | หน้า |
|---|---|
| /demo/ | หน้าหลักดีไซน์ใหม่ (เน้นอุตสาหกรรม) |
| /demo/society.html | CoreDash เพื่อสังคมและการศึกษา |
| /demo/command/ | ศูนย์ควบคุม Command Center (ติดตั้งบนมือถือได้) |
| /demo/lab/ | ห้องแล็บ IoT 3D (81 อุปกรณ์) |
| /demo/plookpun/ | แอปปลูกปั้นสำหรับเกษตรกร (ติดตั้งบนมือถือได้) |

โค้ด ESP32 ของแอปปลูกปั้นอยู่ในไฟล์ zip ชุดเต็ม
