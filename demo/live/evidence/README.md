# บันทึกหลักฐานถาวร CoreDash Live Earth

บอท GitHub Actions (`.github/workflows/live-earth-evidence.yml`) บันทึกที่นี่อัตโนมัติทุก 30 นาที

- `latest.json` บันทึกล่าสุด
- `index.json` รายชื่อไฟล์รายวัน
- `ปปปป/ดด/ปปปป-ดด-วว.jsonl` บันทึกทั้งวัน 1 บรรทัดต่อ 1 บันทึก (วันที่ตามเวลาไทย)

แต่ละบันทึกระบุดาวเทียม วันเวลาของภาพ ลิงก์ต้นทาง และลายนิ้วมือ SHA-256 ที่ต่อโซ่กับบันทึกก่อนหน้า (`prev_sha256`)

ตรวจทั้งโซ่: `node scripts/verify-live-earth-evidence.mjs`

ข้อมูลจากแหล่งเปิด อาจล่าช้าหรือคลาดเคลื่อน ไม่ใช่ประกาศทางการ · แจ้งข้อผิดพลาด CoreDash 081-923-2380
